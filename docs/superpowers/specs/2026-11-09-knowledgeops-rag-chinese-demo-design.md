# KnowledgeOps RAG 中文透明演示设计

## 目标

将独立仓库 `wml516518/knowledgeops-rag` 改造成一个全中文、公开可操作、能够清晰解释 RAG 核心过程的技术知识库演示。

访客可以使用公共样例文档，也可以在自己的临时演示会话中上传、检索、删除和重置文档。页面重点展示：用户问题如何被向量化、如何从向量索引或 Supabase pgvector 中检索相关分块、这些分块如何组成上下文，以及最终回答如何引用来源。

系统必须诚实区分真实云端 RAG 与本地演示 RAG，不能把静态答案或本地相似度检索标记为 Supabase pgvector 的真实结果。

## 语言与内容

- 页面、状态、操作、错误、样例问题、回答、引用、元数据和 README 全部使用中文。
- 技术名词保留标准写法：RAG、Embedding、Supabase、pgvector、DashScope、DeepSeek、topK。
- `frontend/index.html` 使用 `lang="zh-CN"`。
- 页面标题：`KnowledgeOps RAG｜向量检索知识库演示`。
- 页面描述：`一个可上传文档并展示问题向量化、相似度检索、上下文构建和引用回答过程的中文 RAG 演示。`

## 信息架构

页面继续是可操作工作台，不制作营销落地页。桌面采用三栏布局：

### 左侧：文档库

- 公共样例文档区。
- 当前会话上传文档区。
- 上传进度与 `已上传 N/3` 计数。
- 删除单个自有文档。
- 重置当前演示会话。
- 云端/本地模式状态。

### 中间：提问与回答

- 中文问题输入框。
- 3 个可点击的示例问题。
- 提问按钮和处理中状态。
- 最终中文回答。
- 回答中的引用编号，可定位到右侧命中分块。
- 当前会话的问答历史，可重新打开。

### 右侧：RAG 执行轨迹

按时间顺序展示：

1. 原始问题与清洗后的检索文本。
2. Embedding 模型、向量维度、耗时和少量向量数值预览。
3. 检索后端、`topK`、相似度阈值和检索耗时。
4. 按相似度排序的命中文档分块。
5. 发送给生成模型的上下文摘要、字符数和引用编号。
6. 生成模型、生成耗时和总耗时。

移动端将三栏改为顺序工作流或视图切换：文档、提问、执行轨迹。上传计数和当前运行模式始终可见。

## 公共样例文档

内置三篇中文只读文档：

- `Render 部署故障排查手册`
- `FastAPI 接口开发指南`
- `Supabase pgvector 检索说明`

公共样例文档不计入访客的上传配额，不允许删除，也不被“重置当前会话”清理。

## 会话隔离

### 演示会话

- 浏览器首次访问时从后端获取不可预测的临时会话标识。
- 前端保存在本地存储，并随文档和问答请求发送。
- 后端不接受缺少或格式错误的会话标识执行可变操作。
- 访客不需要注册或登录。

### 数据所有权

- 公共样例文档：所有访客只读、可检索。
- 上传文档：只对所属演示会话可见、可检索、可删除。
- 问答历史：只保存在当前会话中。
- 所有数据库查询、向量检索、删除和重置必须包含会话范围。

### 上传上限

- 每个演示会话最多上传 3 个文件。
- 公共样例文档不计入 3 个名额。
- 前端在选择第 4 个文件前提示：`当前演示最多上传 3 个文件，请先删除已有文件后再上传。`
- 后端独立执行相同校验，返回明确的 `UPLOAD_LIMIT_REACHED` 错误码和中文信息。
- 数据库为每个会话提供 1～3 的上传槽位并建立唯一约束，防止并发请求绕过上限。
- 删除文件后释放槽位；重置当前会话后恢复为 `0/3`。

### 生命周期

- 云端演示数据带创建和过期时间，由清理任务删除过期文件、向量分块和问答记录。
- 本地演示模式的数据保存在 Render 进程内存中，服务重启后清空，页面明确说明其临时性。
- 上传文件最大 5 MB，最多产生 80 个分块，只允许 PDF、TXT、MD 和 Markdown。

## 双模式 RAG

### 云端 RAG

云端依赖可用时执行：

1. 使用 DashScope `text-embedding-v4` 将问题转换为 1024 维向量。
2. 调用 Supabase Postgres RPC，以 pgvector 余弦相似度检索公共文档和当前会话文档。
3. 取 `topK` 个高于阈值的分块。
4. 构建带引用编号的上下文。
5. 使用 DeepSeek 兼容 Chat API 生成中文回答。
6. 返回回答、引用与完整执行轨迹。

### 本地演示 RAG

任一云端依赖不可用时执行：

1. 使用确定性的中文 token 特征向量表示问题与文档分块。
2. 在内存向量索引中计算余弦相似度。
3. 根据相同 `topK` 和阈值规则选择分块。
4. 使用检索上下文生成可重复的中文演示回答；如果 DeepSeek 可用，可以仅复用生成模型，但模式仍标记为本地检索。
5. 返回与云端模式相同结构的执行轨迹。

本地模式必须根据每次问题重新计算向量和排序，不能返回固定引用。上传到本地演示会话的文件经过相同分块和向量化后参与当前会话检索。

## API 契约

### 会话

- `POST /api/demo-sessions`：创建临时演示会话并返回标识、过期时间和上传计数。

### 文档

- `GET /api/documents`：返回公共文档与当前会话文档，明确 `scope: public | session` 和 `deletable`。
- `POST /api/documents`：校验会话、配额、文件类型、大小与分块数量，然后索引文档。
- `DELETE /api/documents/{id}`：只允许删除当前会话拥有的文档。
- `POST /api/reset`：只清理当前会话上传、向量和问答历史。

### 问答

`POST /api/ask` 返回：

- `answer`
- `citations`
- `mode: cloud | local_demo`
- `fallback_reason`，仅降级时出现，使用可公开的中文原因
- `trace.question`
- `trace.embedding`
- `trace.search`
- `trace.matches`
- `trace.context`
- `trace.generation`
- `trace.total_duration_ms`

轨迹不得包含密钥、服务角色令牌、完整内部异常、数据库连接信息或用户原始文件内容之外的敏感信息。

## 错误处理

- 第 4 个文件：返回 409 与 `UPLOAD_LIMIT_REACHED`。
- 非法文件或超过 5 MB：返回 400 和中文说明。
- 无法解析文本：返回 400，保留当前配额。
- 删除公共文档或其他会话文档：统一返回 404，避免泄露对象存在性。
- 会话过期：返回 401/410，前端创建新会话并说明旧临时数据已过期。
- 云端问答失败：自动降级到本地演示模式，并在页面显示降级原因。
- 上传索引失败：不创建半成品文档，不占用上传槽位。

## 数据库变更

Supabase 模式增加：

- 文档作用域和会话所有者。
- 1～3 上传槽位及会话唯一约束。
- 会话过期时间。
- 分块继承文档作用域。
- 向量匹配 RPC 接收当前会话标识，只返回公共或当前会话分块。
- 删除文档继续通过外键级联删除向量分块。

后端继续使用服务角色访问 Supabase，但每个仓库方法都必须显式接收会话范围；前端不接触服务角色密钥。

## 可访问性与视觉

- 页面保持安静、工作台式视觉，避免营销式大标题和嵌套卡片。
- 模式、上传计数和处理阶段不仅依赖颜色表达。
- 文件输入、删除、重置、示例问题、提问和视图切换都具有中文可访问名称。
- 删除和重置在当前会话范围内仍需确认，并清楚说明影响对象。
- 相似度使用百分比与可视刻度同时显示。
- 执行轨迹支持键盘浏览，回答引用可以定位对应分块。
- 遵循 `prefers-reduced-motion`。
