# AI Chat Playground 中文化设计

## 目标

将独立仓库 `wml516518/ai-chat-playground` 的公开网页、Prompt 预设、运行状态、错误反馈、页面元数据和仓库说明全部改为中文，同时完整保留现有 React + FastAPI 流式聊天能力。

这次不改变 API 契约，不新增语言切换，也不扩展聊天产品范围。交付目标是一个打开即可使用、所有用户可见信息均为中文的 AI 参数实验台。

## 用户体验

页面继续使用现有的控制区与聊天区布局，但所有信息改为中文：

- 顶部名称：`AI 对话实验室`
- 项目说明：`全栈 AI 项目`
- 服务状态：`正在检查`、`在线 · <模型>`、`服务离线`
- 控制区：`参数控制`
- Prompt 预设：`通用助手`、`代码审查`、`简历优化`、`产品构思`
- 参数：`温度`、`最大生成长度`
- 操作：`清空对话`、`恢复默认参数`、`发送`
- 输入框：`输入你想测试的问题……`
- 空流式消息：`正在思考……`

默认欢迎消息改为：

> 欢迎使用 AI 对话实验室。请选择 Prompt 预设、调整参数，然后发送一条消息开始测试。

清空后的消息改为：

> 对话已清空，可以开始新的测试。

## Prompt 预设

预设名称和系统提示词全部使用中文：

- `通用助手`：提供准确、简洁、实用的中文回答。
- `代码审查`：优先指出缺陷、风险、回归和缺失测试，并提供可执行的修改建议。
- `简历优化`：在不夸大经历的前提下，改善简历表达、结果描述和岗位匹配度。
- `产品构思`：分析用户价值、方案权衡、最小可行范围和实施路径。

预设 ID 保持 `general`、`code-reviewer`、`resume-optimizer`、`product-brainstormer` 不变，避免破坏后端和本地存储中的既有设置。

## 状态与错误

前端不得直接向用户展示英文网络异常。常见错误统一映射为中文：

- 无法连接后端：`暂时无法连接 AI 服务，请稍后重试。`
- 请求超时：`回答生成超时，请缩短问题或稍后重试。`
- 流式连接中断：`回答传输中断，请重新发送。`
- 其他接口错误：`请求失败，请稍后重试。`

后端返回的详细信息只在适合公开展示时附在中文主提示后，不显示堆栈、密钥、内部地址或供应商原始错误。

失败的助手消息仍保留在对话中，但内容使用中文，并允许用户修改问题后重试。

## 元数据与文档

- `frontend/index.html` 使用 `lang="zh-CN"`。
- 标题：`AI 对话实验室｜Prompt 与模型参数测试`。
- 描述：`一个支持流式回答、Prompt 预设和生成参数调节的中文 AI 对话实验项目。`
- `README.md` 改为中文，说明功能、技术栈、本地开发、环境变量、测试和 Netlify/Render 部署。
- 技术名词、模型名、环境变量和代码保持英文原值，不做不准确翻译。

## 可访问性与响应式

- 输入框、预设、温度、最大生成长度和操作按钮都具有中文可访问名称。
- 流式回答容器使用 `aria-live="polite"`，token 更新不移动键盘焦点。
- 键盘可以完成预设选择、参数调整、发送和清空。
- 桌面保留双栏工作区；窄屏下控制区位于聊天区上方，文字和按钮不横向溢出。
- 遵循 `prefers-reduced-motion`，不增加非必要动画。
